# EcoDevice — Premium Green Computing Dashboard

## Run locally
```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Includes Overview, Process Monitor, Eco Actions, Experiment Lab, SDG Impact, charts, gauges, and CSV exports. The app monitors the machine running Streamlit. CPU/RAM readings are not direct electricity measurements. Session records are temporary; export CSVs to preserve them.
